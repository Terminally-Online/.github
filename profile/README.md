Terminally Online is a product studio building tools that empower the fellow terminally online.

## Products

- **[Plug](https://plug.to)** — programmable, condition-driven transactions for EVM chains. Declare what should happen and when; Plug compiles and executes it across protocols.
- **[Poof](https://poof.plug.to)** — your wallet, dealt as cards. Connect and watch your portfolio come back as a playable deck. No two decks match.

## Open source

- [sabre](https://github.com/Terminally-Online/sabre) — minimal, high-performance JSON-RPC load balancer for Ethereum nodes.
- [shrugged](https://github.com/Terminally-Online/shrugged) — declarative PostgreSQL migrations and type-safe Go code generation.
- [go-lbfgsb](https://github.com/Terminally-Online/go-lbfgsb) — L-BFGS-B optimization for Go with minimal setup.
- [tunnel](https://github.com/Terminally-Online/tunnel) — a single passage to any text generation backend, local or hosted.
- [discord-agent](https://github.com/Terminally-Online/discord-agent) — a local-first, always-on agentic teammate for your Discord server.
